# Feature Scope

## MVP features

### Authentication
- Register
- Login
- Logout
- Current-user session
- Protected routes

### Document dashboard
- List documents
- Create document
- Open document
- Rename document
- Delete document
- Search
- Filter by status
- Sort by updated date
- Loading, empty, and error states

### Rich-text editor
- Paragraph
- Headings
- Bold
- Italic
- Underline
- Strike
- Bullet list
- Ordered list
- Blockquote
- Code block
- Link
- Undo and redo

### Structured SOP steps
- Insert step
- Automatic step number
- Editable title
- Editable description
- Optional screenshot
- Delete step
- Save and restore through TipTap JSON

### Autosave
- Debounced saving
- Saved, saving, unsaved, and failed states
- Retry
- Stale-response protection
- Leave-page warning

### Screenshot uploads
- PNG, JPEG, and WebP
- Maximum 5 MB
- Upload progress
- Replace and remove
- Frontend and backend validation

### AI rewriting
- Improve clarity
- Make concise
- Make professional
- Fix grammar
- Preview result
- Apply or cancel
- Undo replacement

### Publishing
- Publish
- Unique slug
- Public read-only page
- Copy link
- Unpublish
- Prevent draft access

### Version history
- Create snapshot
- List versions
- Preview version
- Restore version

## Out of scope

- Teams
- Organizations
- Billing
- Real-time collaboration
- Comments
- Video editing
- Chrome extension
- Advanced analytics
- Complex roles and permissions
