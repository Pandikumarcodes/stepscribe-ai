# StepScribe AI — Project Documentation

StepScribe AI is a frontend-heavy full-stack application for creating SOPs, help articles, onboarding guides, and step-by-step documentation with AI assistance.

## Core development rule

Build only one small function or component at a time:

1. Plan the task.
2. Ask Codex to implement only that task.
3. Review the diff.
4. Run lint, type checking, tests, and build.
5. Test manually.
6. Commit.
7. Continue to the next task.
