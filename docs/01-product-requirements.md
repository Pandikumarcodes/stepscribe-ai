# Product Requirements

## Product name

StepScribe AI

## Tagline

Create polished SOPs and step-by-step guides with AI.

## Problem

Teams often create process documentation manually across multiple tools. Writing, formatting, screenshot handling, publishing, and updating documents become slow and inconsistent.

## Solution

StepScribe AI provides one workspace to:

- Create SOPs and help articles.
- Write using a rich-text editor.
- Add structured step cards.
- Upload screenshots.
- Improve selected text with AI.
- Autosave changes.
- Publish through a public link.
- View and restore document versions.

## Primary user

A software team member, operations employee, support specialist, trainer, or product manager who creates process documentation.

## Main workflow

Dashboard → Create document → Edit content → Add SOP steps → Upload screenshots → Improve with AI → Preview → Publish → Maintain versions
